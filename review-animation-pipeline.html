PIPELINE DECISION

Large organic actor

Anchor → sheet or short keyframe video → select → register. Video can supply organic in-betweens, but only selected frames survive one shared scale, mass anchor, and palette.

Actor on furniture

Stable keys → midpoint edits → canonical fixture composite. Use generated frames only for the actor; every visible sofa/table pixel comes from one immutable plate.

Tiny repeated sprite

A few anchors → code-derived micro-motion. Keep each body fixed, move only its one-pixel tail fan, and coordinate the school procedurally.
